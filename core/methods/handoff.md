# Handoff

For any session that stops before its goal.

1. **Point, never copy.** Name what is already in a commit, a brief or a file by its path or hash; write only what lives nowhere else.
2. **Hold four things:** where the work stands (the last commit and what it proves), what is half-done and why, the next step with its check, and the methods the next session follows.
3. **Leave out** secrets, personal data, and anything the next session finds in one search.
4. **Where:** the final note, at most ten lines, in the work item's folder.
5. **Before a repair handoff:** give the retained builder compile/type feedback first. The fresh receiver gets its own brief and source pointers, not the whole orchestrator history; include the failing regression line, pinned affected plan/result, direct contracts, and full/E2E checks still owed at the checkpoint.

Check: a fresh session reading only the handoff and the files it points to can take the next step without asking.
